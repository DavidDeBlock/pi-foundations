# Dashboard — Context

> ⚠️ **Stub.** To be filled in once the design grilling is complete and ADRs are written.

## One-line summary

Personal dashboard that mirrors and organizes your Chrome bookmarks, browsing history, and YouTube saves — running on a home server, fed by a Chrome extension.

## User

- Solo user (David)
- 2 × Windows machines (personal + shop), both with Chrome signed into the same account
- 1 × in-house Ubuntu server on the same LAN hosting the dashboard
- Chrome Sync keeps both machines' bookmarks/history aligned, so the dashboard deals with one logical Chrome profile

## What the dashboard does (high level)

- **View + organize Chrome bookmarks** — folders + tags, same model for bookmarks and YouTube videos
- **View Chrome history** — full-history bulk import at install, extension pushes new visits in real time
- **Save YouTube videos** — via YouTube Data API, categorized the same way as bookmarks
- **Mirror YouTube saves** — to a private YouTube playlist so the phone app sees them
- **View YouTube history** — via one-time Google Takeout import (v3)

## What's locked in

| Decision | Value | Notes |
|----------|-------|-------|
| Deployment | Self-hosted on Ubuntu server, LAN-accessible | `http://ubuntu-server:<port>` |
| Chrome data ingestion | Extension + one-time bulk import from `History` SQLite | Extension handles ongoing; bulk import gets the long tail |
| Chrome sync direction | Two-way, dashboard wins | Edits in dashboard push to Chrome; Chrome-only edits sync back |
| YouTube data ingestion | Data API for saves; Google Takeout for history (v3) | YouTube API doesn't expose watch history |
| Categorization | Folders + tags, unified for bookmarks and YouTube | Chrome folders map 1:1; tags are dashboard-only |
| YouTube categorization | Dashboard DB is source of truth; YouTube playlist is a mirror | Multi-tag works; mirror can drift briefly |
| App auth | Single password (HTTP Basic) | Password bcrypt-hashed on the server |
| Extension auth | Shared secret API token | Generated by dashboard, pasted into extension config |
| MVP scope | v1 = read-only Chrome bookmarks + categorize + search | Write-back, history, YouTube = later slices |
