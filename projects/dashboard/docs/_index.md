# Dashboard — Docs Index

This folder holds planning and decision artifacts for the **Dashboard** project.

## Files

| File | Purpose |
|------|---------|
| `CONTEXT.md` | Project context: what it is, who's it for, scope, and the high-level decisions made during grilling. |
| `deployment.md` | Production deployment runbook: env vars, systemd unit, backups, firewall, log location, upgrade procedure. |
| `30-plans/` | Fluid planning notes, brainstorming, pre-issue drafts. |
| `35-prds/` | Formal PRDs (product requirements documents) for each feature. |
| `40-decisions/` | ADRs (architecture decision records) — one file per locked-in design choice. |

## Reading order

1. `CONTEXT.md` — orient yourself.
2. `40-decisions/` — see what we've decided and why.
3. `35-prds/` — see what we're building.
4. `30-plans/` — see what we're still thinking about.
